# src/i18n.js — 零依赖国际化内核（取词 / 切语言 / 刷新 DOM）

> 层：引擎（文案） ｜ 159 行 ｜ 不碰业务，只认 `locales/zh.js` + `locales/en.js`
> 一句话：全项目**没有任何写死的中文文案**，所有面向用户的字都从这里出。

## 1. 它解决什么问题（为什么需要它）

中英两份 README 必须结构一致、界面文案必须能整体切换，且 60+ 动作不可能每个都写全文案。
所以需要一个「缺失不空白」的取词器：当前语言 → 英文 → 键名本身，永不返回 `undefined` 给 DOM。
同时把「怎么切语言、切完通知谁」也收敛在这里（`setLang` + 订阅），界面只负责重渲染。

**键名用点分路径**，数组也算合法值（`tList` 取要领/提示列表）。

## 3. 算法与流程（步骤化）

**选语言**（`detectLang` L25-L33）：

```
localStorage 里有且合法 → 用它
否则浏览器 navigator.language 以 'zh' 开头 → 'zh'，其余一律 'en'
```

**切语言**（`setLang(code, {persist=true})` L38-L55）：
不认识的 code → 原样返回；否则写 `current`、可选写 localStorage、
设置 `document.documentElement.lang` 与 `document.title`（都从 `meta` 取）、
最后逐个通知订阅者（**单个订阅者抛错只 `console.warn`**，不影响其它）。

**取词**（`t(key, params)` L85-L91）：

```
lookup(当前语言, key) → 没有就 lookup(en, key) → 还没有就返回 key 本身
数组 → 原样返回；字符串 → interpolate 替换 {name} 占位符
```

`lookup`（L63-L72）按 `.` 逐层下钻，只认 `string` / `Array`。

**刷新静态 DOM**（`applyI18n(root)` L126-L145）：扫 5 种属性 ——
`data-i18n`（textContent）、`data-i18n-html`（innerHTML）、`data-i18n-title`、
`data-i18n-aria`（aria-label）、`data-i18n-placeholder`。

## 6. 易错点与设计取舍

- **`t()` 对数组返回数组**：调用方要自己 `Array.isArray` 判断，或直接用 `tList`。
  把数组塞进 `textContent` 会变成 `a,b`。
- **缺失键不抛错**（返回键名）：这是「界面永不空白」的代价 —— 拼错键**不会**报错，
  只会在界面上显示 `ui.fooBar`。改键名时要全局搜。
- `setLang` 的 `persist` 可以关：测试里用它避免污染 localStorage。
- `hasKey` 同时看当前语言与英文：**英文是兜底语言**，所以只在英文里有的键也算「有」。
- 本文件不 import 任何业务模块（只有 locales），避免循环依赖；`voice/numerals.js` 也刻意
  不 import 它（数词自己成一套）。
