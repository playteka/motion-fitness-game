# 体感健身游戏（Motion Fitness Game）

用普通摄像头做动作识别的健身小游戏：**深蹲 / 箭步蹲 / 俯卧撑 / 臀桥自动计数**，**平板支撑 / 静态臀桥自动计时**，
并且**按「动作要领」一步一步计分**——每达成一个要领就立刻加分、响铃、用语音念出要领，让每一次做对都马上有反馈。

纯前端实现，MediaPipe 姿态模型与 wasm 全部放在本地 `vendor/` 目录，**不联网、不上传画面**。

---

## 快速开始

```powershell
cd motion-fitness-game
node preview-server.js
```

浏览器打开 **http://127.0.0.1:4174** → 点「开启摄像头」→ 允许权限 → 选一个动作 → **侧对镜头站好就能立刻拿分**（不用先点开始）→ 想正式记一组再点「开始训练」。

页面标题旁的 `v1.2` 是版本号；升级后如果行为没变化，按 **Ctrl + F5** 强制刷新缓存。

> ⚠️ 必须通过 `http://127.0.0.1` 打开，直接双击 `index.html`（`file://`）会被浏览器拦截摄像头与 wasm 加载。
> 建议用最新版 Chrome / Edge。首次加载模型约 1~3 秒（本地文件，无网络请求）。

## 计分规则：照着要领做，就一步一步拿分

界面右侧有一张**要领清单**，做对一步就立刻打勾、加分、响铃，当前该做哪一步会高亮。
**整轮要领全部完成**还有额外的满分奖励；计时类动作**每保持 1 秒再加 1 分**。

### 深蹲（每轮满分 45 分）

| 要领步骤 | 判定条件 | 分值 |
|---|---|---|
| ① 侧对摄像头站好，全身入镜、身体直立 | 侧拍视角 + 全身可见 + 身体接近竖直 + 膝角 >150° | +4 |
| ② 髋部向后向下坐（屈髋启动） | 膝角 ≤152° 且髋角打开 | +6 |
| ③ 双膝顺着脚尖方向屈曲下沉 | 膝角 ≤135° | +7 |
| ④ **蹲到大腿接近水平** | 大腿与地面夹角 ≤25°（或髋低于膝） | **+14** |
| ⑤ 蹬地站直，髋膝完全伸展 | 膝角 ≥150° 且髋角回到 ≥130° | +8 |
| 🎁 整轮要领全过 | 上面 5 步同一轮内全部达成 | +6 |

### 箭步蹲（每轮满分 54 分）

| 要领步骤 | 判定条件 | 分值 |
|---|---|---|
| ① 侧对摄像头站好，身体直立、全身入镜 | 侧拍视角 + 全身可见 + 身体直立 + 两腿基本伸直 | +4 |
| ② 一条腿向前迈出，前后脚分开 | 两脚踝前后距离 > 0.45 倍躯干长 | +5 |
| ③ 迈成一大步（前后距离拉开） | 两脚踝前后距离 > 0.9 倍躯干长 | +6 |
| ④ 双膝同时弯曲下沉，前膝约 90° | 更弯的一条腿 ≤118° 且另一条 ≤150° | +11 |
| ⑤ **后膝下降到接近地面** | 后膝离地高度 ≤0.35 倍小腿长 | **+14** |
| ⑥ 前脚蹬地回到站姿 | 两腿重新伸直（需先下沉过） | +8 |
| 🎁 整轮要领全过 | 上面 6 步同一轮内全部达成 | +6 |

> 用户最关心的「站好就能得分」在这里：**只要侧对镜头站好、前后脚分开站，就已经拿到 ① 甚至 ② 的分了**，
> 不用等做完一整个动作才有反馈。

### 俯卧撑（每轮满分 40 分）

| 要领步骤 | 判定条件 | 分值 |
|---|---|---|
| ① 双手撑地，身体成一条直线 | 趴撑姿 + 身体直线角 ≥165° + 不塌腰不撅臀 | +5 |
| ② 收紧核心，肘部弯曲下沉 | 肘角 ≤140° | +7 |
| ③ **肘角弯到 90° 以内** | 肘角 ≤95° 且身体仍成直线 | **+14** |
| ④ 推起还原，手臂完全伸直 | 肘角 ≥145°（需先下放过） | +8 |
| 🎁 整轮要领全过 | 上面 4 步同一轮内全部达成 | +6 |

### 臀桥（每轮满分 39 分）

| 要领步骤 | 判定条件 | 分值 |
|---|---|---|
| ① 仰卧屈膝，双脚与髋同宽踩实 | 仰卧屈膝姿（肩贴地、膝离地） | +5 |
| ② 收紧臀部，把髋部向上顶起 | 髋抬起量 > 0.15 倍躯干长 | +6 |
| ③ **顶到肩-髋-膝接近一条直线** | 髋抬起量 > 0.35 倍躯干长 | **+14** |
| ④ 臀部有控制地落回地面 | 回到地面（需先顶起过） | +8 |
| 🎁 整轮要领全过 | 上面 4 步同一轮内全部达成 | +6 |

### 平板支撑（一次 70 分 + 每秒 1 分）

| 要领步骤 | 判定条件 | 分值 |
|---|---|---|
| ① 小臂在肩下撑地，把身体撑起来 | 肩离地 + 手贴地 + 肘角合法 | +8 |
| ② 头、背、髋、脚踝成一条直线 | 身体直线角 ≥158° + 不塌腰不撅臀 | +12 |
| ③ 稳定保持 3 秒 | 保持满 3 秒 | +10 |
| ④ 稳定保持 10 秒 | 保持满 10 秒 | +15 |
| ⑤ 稳定保持 30 秒 | 保持满 30 秒 | +25 |
| ⏱ 每保持 1 秒 | 姿势有效期间 | +1/秒 |

### 静态臀桥（一次 63 分 + 每秒 1 分）

| 要领步骤 | 判定条件 | 分值 |
|---|---|---|
| ① 仰卧屈膝，双脚踩实与髋同宽 | 仰卧屈膝姿 | +6 |
| ② 顶起髋部到最高点 | 髋抬起量 > 0.32 倍躯干长 | +12 |
| ③ 臀部收紧保持 3 秒 | 保持满 3 秒 | +10 |
| ④ 保持 10 秒 | 保持满 10 秒 | +15 |
| ⑤ 保持 20 秒 | 保持满 20 秒 | +20 |
| ⏱ 每保持 1 秒 | 姿势有效期间 | +1/秒 |

### 音效与语音反馈（每一步都有）

| 时机 | 反馈 |
|---|---|
| 达成一个要领 | **音阶上行的一声铃**（第几步就响第几级音）+ 画面飘出 `+12` 加分动画 |
| 整轮要领全过 | 三音上行「满分」和弦 + `要领全过 +6` 飘字 |
| 每个要领第一次达成 | **语音念出该要领**（例如「迈成一大步」），后面重复时只响铃不念，避免刷屏 |
| 每跨过 50 分 | 上扬提示音 + 语音报「100 分」+ 字幕祝贺 |
| 有效次数 +1 | 五声音阶计次音 + 语音报数 |
| 动作没算数（半程 / 太快 / 塌腰） | 低频「噗」声 + 字幕指出问题 |
| 计时类保持中 | 每秒一声轻点 + 分数持续上涨 |
| 达标 / 结束本组 | 庆祝和弦 + 达标飘字 + 结算面板（含得分与漏掉的要领） |

音效与语音都可以在顶栏一键关闭。

## 完整判定表（计数 / 计时口径）

| 动作 | 有效计数依据 | 不计入的常见情况 |
|---|---|---|
| **深蹲** | 大腿蹲到接近水平（与地面夹角 ≤25°）再站直 | 半蹲、下蹲过快（<0.62 秒）、膝盖内扣、上身趴太低 |
| **箭步蹲** | 前后膝都弯到 ~90°、后膝接近地面，回到站姿 | 只弯前腿、后膝离地太高、下沉过快（<0.75 秒） |
| **俯卧撑** | 趴撑姿下肘角弯到 90° 以内再推直 | 塌腰 / 撅臀、幅度不足、过快（<0.42 秒） |
| **臀桥** | 髋部顶到「肩-髋-膝接近一条线」再落回 | 只顶一半、用惯性甩起（<0.32 秒） |
| **平板支撑** | 撑地 + 身体成一条直线 的累计时间 | 塌腰 / 翘臀 / 膝盖着地；垮掉超 1.2 秒自动暂停计时 |
| **静态臀桥** | 顶到最高点并保持的累计时间 | 臀部落下即暂停；没顶到位会提示「顶高一点」 |

「半程 / 未计」单独统计，**不会**混进有效次数。想宽松一点可以关掉顶栏的「✅ 严格模式」。

### 机位很重要

**六个动作都建议侧对镜头**（身体与镜头垂直），这样关节角度才是真实角度：

- 与摄像头相距 **2~3 米**，让**全身入镜**（头顶到脚都在画面里）；
- 深蹲 / 箭步蹲：侧对镜头站立，画面里能同时看到脚踝、膝盖、髋、肩；
- 俯卧撑 / 平板支撑：人躺/趴的方向与镜头垂直，手和脚都在画面内；
- 臀桥 / 静态臀桥：侧躺位，能同时看到肩、髋、膝、踝；
- 光线均匀、背景别太乱，穿贴身一点的衣服识别更稳。

> 计分门槛之一是「侧对摄像头 + 全身入镜」，如果一直没拿到第①步的分，先检查机位而不是动作。

## 站好了却没反应？按这三步排查

**① 先确认版本。** 页面标题旁应显示 `v1.2`。如果没看到，说明浏览器还在用缓存的旧版本 —— 按 **Ctrl + F5**（Mac 是 Cmd + Shift + R）强制刷新。

**② 看画面下方的状态条。** 它会一直告诉你当前卡在哪：

| 状态条文字 | 含义 |
|---|---|
| 没检测到人体：请站到画面中间… | 模型没找到人 → 见下面「常见原因」 |
| 下一步「侧对摄像头站好…」：检测到你在正面/斜对镜头 | 找到了人，但机位不对 |
| 下一步「…」：没看清你的全身 | 找到了人，但有人体部位出画了 |
| 已识别到你 ✓ 保持这个位置做动作 | 一切正常，做动作就行 |
| 摄像头未开启 / 模型加载中… | 管线还没起来 |

**③ 打开右上角「🐞 识别指标」。** 画面下方会实时列出识别器看到的数字，例如：

```
视角 侧面✓(0.18) · 全身 ✓ · 双腿可见 ✓ · 躯干倾角 6° · 膝 176° · 肘 172° ·
髋 172° · 身体直线 175° · 髋抬起 -0.98 · 大腿离水平 88° · 可见度 0.94 · 状态 running
```

对照判断：

| 症状 | 原因 | 处理 |
|---|---|---|
| `视角 正面✗(0.9)` | 你其实是正面/斜对着镜头 | 转身侧对摄像头，让身体与镜头垂直 |
| `全身 ✗` | 有人体部位出画 | 退后 1~2 步，让头顶到脚都进画面 |
| `没检测到人体` | 太远/太近、逆光、背景与衣服同色、分辨率太低 | 靠近一点、面对光源、换深色/浅色衣服、换 720p 以上摄像头 |
| `躯干倾角` 长期 > 32° | 摄像头是斜的或人站歪了 | 摆正摄像头（或用书本垫平） |
| 数字正常但没打勾 | 卡在某一步的阈值上 | 状态条会直接写出还差多少（如「再蹲低一点：现在大腿离水平还差 12°」） |

> 重要：**识别从你选好动作那一刻就开始了，不需要先点「开始训练」**。
> 只要侧对镜头站好，「站姿」那一步的分和铃声会立刻出现。点「开始训练」只是开始计时记一组。

## 其它功能

- **实时状态反馈**：画面下方的状态条永远在告诉你「现在是什么状态、卡在哪一步、还差多少」，
  选好动作就能拿分，不用先点开始。
- **🐞 识别指标面板**：一键显示识别器看到的全部原始数字（视角、可见度、各关节角度），机位问题一眼定位。
- **实时骨架叠加**，并实时标注当前动作关注的关节角度（膝/肘/髋/身体直线角）。
  - **🦴 火柴人**：一键开关骨架显示。关闭后画面上只剩摄像头画面（连地面参考线一起隐藏），
    识别与计分照常运行 —— 想录一段干净的视频、或者觉得线条晃眼时用。快捷键 <kbd>S</kbd>。
  - **📐 角度**：单独控制关节角度标注，和火柴人互不影响（比如可以只留角度数字、不画线条）。
- **姿势纠错**：蹲太浅、膝盖内扣、塌腰、撅臀、手没撑地、顶得不够高，都有字幕 + 语音提示。
- **目标与进度环**：可设目标次数/秒数，达标弹出庆祝动画并自动保存记录。
- **最佳成绩 + 训练记录**：按动作记录最好成绩与最高得分，本机 localStorage 保存最近 40 组。
- **快捷键**：`1`~`6` 切动作、`空格` 开始/暂停、`R` 重置计数、`Esc` 结束本组、`M` 镜像、`S` 火柴人、`F` 全屏。
- 训练时自动申请屏幕常亮（Wake Lock），切到后台会自动暂停。

### 识别原理（为什么阈值不挑身高和机位）

所有判据都用**与人体尺度无关的量**：

1. **关节角度**（度）——与身高、与镜头距离无关；
2. **长度比例**（除以躯干长）——判断「髋抬起多少」「手有没有撑到地」「后膝离地多高」「迈步多大」；
3. **上下先后关系**（比较 y 坐标）——与左右朝向、镜像无关；
4. 关键点先做**宽高比校正**（x 乘画面宽高比），保证算出来的 30° 真的是 30°；
5. 再做 **One Euro 滤波**（自适应低延迟平滑），既压抖动又不拖慢响应。

所以同一套阈值可以适配不同的人、不同的机位（只要侧对镜头）。

计分还做了两条防作弊：
- **站着不动只能拿到「站姿」那一步的分**，之后不会重复加分（有测试守着）；
- 步骤带**轮次状态**（例如「推起还原」「有控制地落回」必须先把动作做下去才会给分），不能靠站着反复领分。

## 想自己调分值 / 阈值

- **改分值或要领文案**：编辑 `src/steps.js`，每个步骤就是一个 `{ id, label, points, check }`；
  `check(frame, det)` 返回 `true` 即表示这一步达成，`det` 可以读到识别器内部状态
  （例如 `det.cycleDescended` 表示这一轮是否已经蹲下去过）。
- **改判定阈值**：编辑 `src/exercises.js` 里每个动作顶部的常量，都有中文注释：
  - `SQUAT.thighParallel`：大腿与地面夹角多少度算「蹲到位」（默认 25°，越小越严）；
  - `LUNGE.backKneeDrop`：后膝离地高度 / 小腿长（默认 0.35，越小越严）；
  - `PUSHUP.elbowFull`：俯卧撑底部肘角（默认 92°）；
  - `BRIDGE.upRise` / `BRIDGE_HOLD.holdRise`：臀桥顶起高度（以躯干长为单位）；
  - `PLANK.bodyStraight`：平板支撑「身体成一条线」的最低角度（默认 158°）；
  - `HoldDetector.graceMs`：计时类动作的容错宽限期（默认 1200ms）；
  - `STEP_PLANS.*.repBonus`：整轮满分奖励分值。

改完请跑 `npm test`，测试里已经写好了这些动作的标准幅度，能立刻告诉你是不是调过头了。

## 隐私与资源占用

- 画面只在本机浏览器里处理，**没有任何上传**；模型与 wasm 都是本地文件，断网可用。
- 默认使用轻量模型（`pose_landmarker_lite`，约 5.8MB）；顶栏可切到完整模型（约 9.4MB，更准但更吃性能）。
- 推理优先用 GPU（WebGL），不可用时自动回退 CPU。

## 已知限制

- 需要**侧对镜头**才能准确测角度；正面拍摄时深蹲/箭步蹲的深度判定会偏乐观（正面视角只用于「膝盖内扣」检查）。
- 遮挡严重（宽松衣服、深蹲时腿部被躯干挡住）或光线很暗时，关键点会抖，识别会短暂进入「没看到你」状态，恢复后会自动继续，不会串数。
- 摄像头授权卡住时页面会在 25 秒后提示重试。
